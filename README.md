## 🌟 Key Features & Innovations

- **🚀 Live Cloud Deployments Hub**: Dedicated section and hero badge spotlighting live production applications deployed on Vercel, Render, and GitHub Pages.
- **💻 Interactive Code Studio Window**: MacOS-style IDE mockup in the Hero with live interactive tabs (`developer.json`, `stack.config.ts`, `live.deploy.env`) and docked verified developer badge.
- **⌨️ Developer Command Palette (`Ctrl + K`)**: Keyboard-driven quick-access terminal for instant section jumping, external deployment launches, theme toggling, and email copying.
- **🔎 Real-Time Technical Skills Search & Filter**: Search bar with real-time matching highlights and category tabs for instant tech stack discovery.
- **📊 Bento Grid Engineering Profile**: Modern Bento layout presenting academic achievements (MCA pursuing at CBS, BCA with 9.04 CGPA from KLE Tech), machine learning competencies, and leadership roles.
- **🖥️ Browser Mockup Project Cards**: Realistic browser chrome headers with simulated URL address bars and live status pills for deployed web applications.
- **📋 1-Click Clipboard Copy**: Instant email copy button with animated checkmark feedback.
- **🌓 Dark / Light Theme Persistence**: Smooth toggle with persistent state stored in `localStorage`.
- **📱 100% Responsive Design**: Zero horizontal overflow verified across 375px (Mobile), 768px (Tablet), and 1240px+ (Desktop).
